# Рост ферм: перенос в работе

Реализован отдельный планировщик FarmGrowthPlan. Правила сверены с исходными FarmChunk, CivData и SyncGrowTask ветки 1.8-Beta-6; основные действия FarmChunk также проверены по байткоду установленного старого серверного JAR.

Сохранены исходные особенности:

- Шесть выборов растения за цикл при росте города 100%; множитель равнины 1,5 применяется до округления числа выборов.
- Дополнительный вероятностный выбор использует целую часть остатка роста города от деления на 100, без множителя биома и числа выборов.
- Растения выбираются с возвращением из снимка: повторный выбор того же растения не прибавляет несколько стадий в одном цикле.
- Пшеница, морковь и картофель растут до возраста 7, адский нарост до 3, какао до 2. Свет и влажность не проверяются.
- Для стеблей нужны все четыре соседа внутри чанка, свободный сосед и отсутствие соответствующего плода рядом. Это правило применяется и к молодым стеблям. Зрелый стебель получает шанс 20% на один случайный соседний блок; занятый выбранный блок не вызывает поиска другого места.
- Открытая область -64 < x < 64 и -64 < z < 64 исключена из роста, как в оригинале. Современные высоты и имя исходного мира сохраняются.

Семь тестов планировщика проверяют эти правила, включая границы, вероятностные пороги и выбор с повторами. Ещё три теста журнала проверяют сохранение долга роста, повторное открытие базы, однократное списание цикла, пустые циклы, блокировки владельца и конфликты с мельницей. Проверки регистрации включают отрицательные координаты, разные миры и несколько записей одного участка. Общая сборка проходит: 453 теста, ошибок и пропусков нет.

Планировщик подключён к ProductionService. Для завершённых ферм используется чанк угла, а не весь шаблон; последняя завершённая запись участка исключает двойной рост. Интервал берётся из farm.grow_tick_rate, число выборов из farm.grows_per_tick, множитель биома из компонента ActivateOnBiome. Сканируется вся современная высота мира. Направление какао сохраняется при изменении возраста.

Обычный рост контролируемых культур отменён; огород лагеря по-прежнему обрабатывается напрямую существующим CampService. Повторная нативная проверка лагеря в этом этапе не выполнялась. Механика общей активации/отключения зданий остаётся отдельной незавершённой задачей; здесь проверяются статус COMPLETE и положительное здоровье фермы.

FarmGrowthStore учитывает циклы во время работы сервера, в том числе при выгруженном чанке. После запуска время простоя не добавляется, ранее накопленный долг сохраняется. Загруженная ферма отрабатывает до одного цикла за проход секундного обработчика; для каждого цикла берётся свежий снимок. Это устраняет потерю последовательного роста при повторном применении старого снимка. Изменения before/after сохраняются в общем журнале производства; до завершения защищены растения и блоки под ними. После сохранения мира SQL-транзакция завершает операцию и списывает ровно один цикл. Разрушение фермы сбрасывает её часы и долг.

На Paper 1.21.11 проверены рост всех семи культур по одной стадии, сохранение направления какао, остановка на зрелой пшенице, появление арбузов/тыкв и три последовательные стадии по трём сохранённым циклам. Какао пережило перезапуск с тем же возрастом и направлением. Серверный location_check подтвердил свет 0 внутри закрытого участка, BlockData — влажность грядки 0; пшеница выросла на одну стадию. Клиентский счётчик света оказался непригоден для этой проверки, поэтому использован ответ самого сервера.

Введено прерывание world-saved: мир уже содержит пшеницу возраста 1, в журнале остаётся одна ячейка, долг равен 1. Применение костной муки не продвинуло растение. После штатной остановки и запуска без флага прерывания возраст остался 1, долг стал 0, журнал очистился. Это не испытание отключением питания. Первоначальная проверка клиента читала возраст раньше получения пакета изменения блока; ожидание обновления исправлено в тестовом помощнике, состояние на сервере подтверждено отдельным подключением.

Команда execute unless loaded подтвердила выгрузку настоящего чанка. После сдвига часов на три прошедших интервала сервер начислил три цикла, не создавая операций роста. Долг пережил перезапуск; после загрузки чанка пшеница перешла с возраста 1 на 4, долг обнулился. После оптимизации сканирования и проверки регистрации итоговый JAR дополнительно проверен одним реальным циклом роста.

Временные участок, стены/крыша для темноты, почва и пол удалены. Исходные база и playerdata восстановлены на остановленном сервере с проверкой SHA-256; integrity_check=ok, foreign_key_check пуст, дипломатия нейтральна. Старый сервер 1.11.2 не изменялся. Полный естественный путь строительства фермы, общий сценарий города/войны/чудес/победы и оставшиеся производства ещё не проверены целиком. Изменения этого этапа сохраняются локально.
